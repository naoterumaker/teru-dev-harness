Codex を主実装（実装・テスト・コミット）に置く。
Claude Code は UI/computer-use、画面操作、デザイン微調整、再現手順の確定に寄せる。

Why:

- Codex は実装のスループットが高く、差分駆動で安定しやすい
- Claude は UI/操作・観察→手順化が強く、補助線として効く
- 役割分担を固定すると、委任判断が速くなり事故が減る
